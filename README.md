# Электронная библиотека 📚

## Описание проекта
Электронная библиотека — это программа на Python для управления книгами и читателями. Она позволяет добавлять книги, искать и сортировать их, выдавать книги читателям и сохранять отчёты в файлы.

## Возможности
- Добавление книг в библиотеку
- Хранение информации о читателях
- Поиск книг по названию
- Сортировка книг по году издания
- Выдача и возврат книг
- Проверка доступности книг
- Импорт данных из CSV
- Экспорт отчётов в JSON
- Обработка ошибок
- Использование генераторов и полиморфизма

## Структура проекта
- `models.py` — модели книг, читателей и выдач
- `file_manager.py` — чтение CSV и запись JSON
- `library_service.py` — поиск, сортировка и бизнес-логика
- `main.py` — запуск программы
- `books.csv` — файл с данными о книгах
- `report.json` — файл отчёта
- `README.md` — описание проекта

## Используемые технологии
- Python 3
- `dataclasses`
- `typing`
- `csv`
- `json`
- `logging`

## Основные классы

### Book
Хранит информацию о книге: номер, название, автора, год издания и статус доступности.

### Reader
Хранит информацию о читателе: номер, имя и электронную почту.

### Loan
Описывает выдачу книги читателю и её возврат.

### LibraryService
Позволяет добавлять книги, искать их по названию, сортировать по году издания и получать краткую информацию об объектах.

## Принципы программирования
- **ООП** — использование классов и объектов.
- **Композиция** — связь книги и читателя через выдачу.
- **Полиморфизм** — один метод `get_summary()` работает с разными объектами.
- **Протокол Summarizable** — задаёт требование к методу получения краткой информации.
- **Генератор** — позволяет читать книги из CSV постепенно с помощью `yield`.
- **Линейный поиск** — поиск книг по части названия.
- **Пузырьковая сортировка** — сортировка книг по году издания.

## Формат CSV

Пример содержимого файла `books.csv`:

```csv
book_id,title,author,year,is_available
1,Война и мир,Лев Толстой,1869,True
2,Преступление и наказание,Федор Достоевский,1866,False
```

## Запуск проекта

1. Установите Python 3.
2. Откройте папку проекта в Visual Studio Code.
3. Убедитесь, что все файлы проекта находятся в нужной папке.
4. Запустите программу командой:

```bash
python main.py
```

## Обработка ошибок
В проекте используется собственное исключение `LibraryError`. Оно помогает обрабатывать ситуации, например попытку выдать уже выданную книгу или открыть отсутствующий файл.
